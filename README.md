# Баарны бүжигчдийн орлого, бонусын систем (Boudoir & Night)

3 салбар баарны (ARUM CLUB, ALOHA CLUB, MAN CLUB) бүжигчдийн өдөр тутмын орлого, үзүүлбэр, ирц, суулт болон бонусын тооцооллыг гар утсаар болон компьютерээс хөтлөх зориулалттай систем.

---

## Гол боломжууд

### 1. Бармен горим (Mobile-first хялбар интерфэйс)
- **Салбар ба Огноо сонгох:** 3 салбар (ARUM CLUB, ALOHA CLUB, MAN CLUB)-аас өөрийн салбарыг сонгоно.
- **Бүжигчин сонгох:** Бүжигчний тайзны нэрийг сонгоход **Данс эзэмшигчийн нэр** болон **Дансны дугаар** сангаас автоматаар дуудагдаж бөглөгдөнө. (Бармен гараар урт дансны дугаар бичих шаардлагагүй).
- **Тоолуур товчнууд [ - ] [ тоо ] [ + ]:** 
  - **TIP (Тип):** 15,000₮
  - **Энгийн Wine:** 100,000₮
  - **Үнэтэй Wine:** 120,000₮
  - **Энгийн суулт:** 70,000₮
  - **Уулттай суулт:** 120,000₮ / 130,000₮
  - **Extra бонус:** 200,000₮ (тоолуураар болон чөлөөт дүнгээр нэмэх боломжтой)
  - **Торгууль:** Хасагдах торгуулийг шууд оруулах
- **Автомат бодолт:** Бүжигчний авах нийт дүн тооцоологдож шууд харагдана.
- **Өдрийн бүртгэлийн жагсаалт:** Тухайн өдөр тухайн салбарт орсон бүх бүжигчдийн жагсаалт, өдрийн нийт дүн доор нь шууд харагдана.

### 2. Ерөнхий Нягтлан бодогчийн горим (Админ эрх)
- **Нэгдсэн тайлан & Бонус:**
  - 3 салбарын нийт олгох бонус, TIP тоо, Wine (Энгийн ба Үнэтэй) тоо, Суултын тоо, Extra тоог хянах.
  - Огноогоор шүүх (Өнөөдөр, 7 хоног, Энэ сар, Дурын хугацаа).
  - Салбараар шүүх (Бүх салбар эсвэл тусдаа салбар).
  - Бүжигчин тус бүрээр нийт ажилласан ээлж, гүйцэтгэл, нийт олгох дүнг банкны данстай нь нэгтгэн харах.
- **Excel татах (Export):**
  - Сонгосон хугацааны тайланг банкны шилжүүлэг шууд хийхэд зориулан форматласан Excel (.xlsx) файл болгон 1 товшилтоор татах.
- **Бүжигчдийн лавлах сан (CRUD):**
  - Шинэ бүжигчин нэмэх (Тайзны нэр, Данс эзэмшигч, Дансны дугаар, Салбар, Төрөл: Үндсэн/Халтуур, Утас).
  - Мэдээлэл засах (Данс солигдсон үед шууд засах).
  - Бүжигчнийг устгах / идэвхгүй болгох.
- **Тарифын үнэ тохиргоо:**
  - Салбар бүрийн TIP, Энгийн Wine (100k), Үнэтэй Wine (120k), Энгийн суулт (70k), Уулттай суулт (120k/130k), Extra (200k) ханшийг ерөнхий нягтлан хүссэн үедээ шууд өөрчлөн хадгална.

## Дизайн & Хэв маяг
- **Dark Theme & Bar Minimalist:** Гүн бараан өнгө (Deep Slate/Charcoal), хүрэл алтан шаргал акцент өнгө (Warm Amber/Gold).
- **Icon-д суурилсан:** Элдэв өнгө алагласан эможи ашиглахгүй, цэвэрхэн минимал SVG дүрсүүд (Lucide Icons).
- **Responsive:** Гар утаснаас нэг гараар ажиллахад тохиромжтой том товчнууд болон компьютерт тохирсон өргөн хүснэгтэн удирдлага.

## Ажиллуулах заавар

1. **Эхлүүлэх:**
   - Хавтас доторх `start_app.bat` файл дээр 2 дарж ажиллуулна.
   - Эсвэл терминал дээрээс:
     ```bash
     python server.py
     ```
2. **Вэб хөтчөөс орох:**
   - Компьютер дээрээ: [http://localhost:8000](http://localhost:8000)
   - Гар утаснаас орохдоо: Компьютер болон утас хоёр нэг Wi-Fi сүлжээнд байх үед компьютерийнхээ локал IP хаягаар орно (Жишээ нь: `http://192.168.1.X:8000`).
